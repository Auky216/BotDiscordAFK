# Política de seguridad

Para reportar una vulnerabilidad, usa **Report a vulnerability** en la pestaña Security de GitHub si está disponible. Si no aparece, contacta al mantenedor de forma privada a través de su perfil de GitHub. No publiques tokens, claves, datos de miembros ni instrucciones de explotación en un issue público.

Incluye una descripción del impacto, pasos de reproducción y la versión o commit afectado. Rota de inmediato cualquier credencial que se haya expuesto.
